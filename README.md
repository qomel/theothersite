# theothersite

Personal portfolio of **Dominik Pazurek** — Frontend Developer.

Built with Next.js 15 (App Router), React 19 and Tailwind CSS v4.

## Stack

- **Framework** — Next.js 15 App Router
- **Styling** — Tailwind CSS v4 + custom CSS animations
- **Fonts** — Cormorant Garamond, Italiana, DM Sans (via `next/font/google`)
- **Canvas** — vanilla WebGL for the 3D wireframe sphere

## Features

- Sticky hero with drag-to-rotate 3D wireframe sphere
- Custom cursor with `mix-blend-mode: difference`
- Fullscreen navigation with `clip-path` reveal animation
- Bidirectional tech-stack marquee
- Projects list with floating hover preview card
- Scroll-driven sticky resume timeline
- Cream-themed footer with specular glow

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
